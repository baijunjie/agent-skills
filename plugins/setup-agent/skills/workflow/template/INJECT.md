# 工作流

本节只定开工前与交付前何时调用什么、按什么顺序、何时跳过；每一步怎么做以对应的 skill 为准。
拿不准就汇报：停下，写清要定的事（有哪些选项）或缺的信息，连同已查明的情况一起报出，由收到汇报的一方（用户，或由派发者转给用户）决定后再继续，不要自行决定。

## 开工前

- 先确认分支是最新的：只 fetch 当前分支要合回去的那个分支（不必 fetch 全部），再看当前分支相对它有没有落后，落后就先对齐再动手；
  对齐不改写已推送、又不是自己独用的分支的历史。
<!-- if-installed: agent-docs -->
- 按 `agent-docs` skill 了解项目上下文。
<!-- end-if -->

## 交付前

自检针对本次改动全部写完后的一次**完整交付**，不是每一次编辑，阶段性提交也不算；用户要求推送、发 PR 或合并也算交付。交付时：

- 有需要用户确认的内容（待拍板的决定、要问的问题、用户说过要先过目的改动、影响较大的自行决定），
  先汇报，按反馈改完再重新判断。
- 没有就按以下顺序逐项自检：

<!-- if-installed: agent-unit-test -->
1. **补单元测试**：按 `agent-unit-test` skill 为本次改动补测试。
<!-- end-if -->
<!-- if-installed: agent-gallery -->
2. **gallery**：按 `agent-gallery` skill 让 gallery 跟上并跑快速检查，要不要做、跑哪个范围以它的判定为准。
<!-- end-if -->
<!-- if-installed: agent-change-check -->
3. **改动检查**：按 `agent-change-check` skill 审本次改动；审查通过、或剩余意见已由用户定下并按决定改完后，才进入下一步。
<!-- end-if -->
<!-- if-installed: agent-docs -->
4. **文档更新**：本次改动要更新给后来者看的文档时，按 `agent-docs` skill 更新。
<!-- end-if -->
<!-- if-installed: agent-gallery -->
5. **UI 预览**：按 `agent-gallery` skill 给用户预览，要不要预览、要不要等确认以它的判定为准。
<!-- end-if -->
6. **格式化与检查**：先执行项目约定的格式化命令改写代码，再按改动范围跑检查，确认都通过；不通过就改，改完按改后的改动重新定范围再跑。范围：


   - **整套**是项目在指令文件或文档里写明的检查命令（格式检查、类型检查、Lint、构建、测试中写明了的）。没写明的，以项目配置里现有的这几类本地检查命令为整套（不含发布、部署这类有外部副作用的），并告知用户把整套写进指令文件；一条都没有的，告知用户这次没有可跑的检查。
   - **只改了构建、类型检查与测试都不读的文件**（通常是文档、指令文件、skill 与子代理定义；有构建或测试校验它们的不算）：只跑覆盖到这些文件的格式检查与 Lint，没有就不跑并告知用户。
   - **除上一条那类文件外，改动只在一个包或模块内**、项目在指令文件或文档里为它写明了自己的检查命令、且它不被其它包依赖：跑这个包的检查，包外那类文件另按上一条跑。
   - **其余跑整套**：改到被多处依赖的共享层（公共代码与类型，被其它包依赖的包，格式化、类型检查、构建、测试与 Lint 的配置，依赖版本）、跨多个包，或判断不了的。

   定范围时的改动指本分支相对它与目标分支分叉点的全部改动（直接在目标分支上改的，相对改动前）；rebase 或 merge 带进了新代码的，还包括带进来的那段（rebase 或 merge 前后两个分叉点之间的差异）与解冲突改过的地方，不只是原来改动的那部分。

格式化与检查只在「格式化与检查」这一步跑、在最终提交与交付（推送、发 PR 或合并）之前；前面各步不另跑（各步为确认自己的改动而跑的相关测试不算）。

- **自己又改了行为、逻辑或界面**（按改动检查的意见、按预览反馈、为通过检查、解冲突时改的）：对这部分新改动从第一个相关的步骤起重走；只改格式、类型标注这类机械问题的不重走。
- **同一份内容不重跑**：自检后内容没变的（如只压平），之后推送、发 PR 或合并不重做；rebase 或 merge 带进了别人的新代码的，
  重跑格式化与检查，范围把带进来的代码算进改动。
<!-- if-installed: agent-gallery -->
- **收尾**：格式化与检查通过后、分支合并或提 PR 之前，按 `agent-gallery` skill 收尾清理；放弃这次改动或删掉工作副本之前同样要收尾。
<!-- end-if -->
