## 分派子代理

派子代理出去有两种理由——**要一个干净的视角**（审自己刚写的代码、写文档，你手上的
上下文会带着偏见），或**把机械活挪出主上下文**（批量搜索、定位、替换）。

**怎么交代：**

- 一次只交代一件事，说清完成判据。
- 背景要给全：你没写进去的前提它一概不知道，别指望它自己补。
- 让它报结论，不要它复述过程。
- 不要让多个子代理同时修改同一任务范围。

**选谁执行：有专职子代理负责的交给它**；没有的**按任务难度选，不要一律用最强的**——
批量搜索、代码定位这类机械活给最便宜的档，架构设计与技术选型才给最强的。

| agent | 用途 |
|---|---|
| `mechanical` | 批量搜索、代码定位、批量替换、格式化、简单文本与数据处理 |
| `implement` | 编写具体逻辑代码、实现已定方案、目标明确的重构与修 Bug。默认的性价比选择 |
| `investigate` | 跨模块疑难排查、根因定位、大范围重构 |
| `architect` | 架构设计、跨模块改造方案、技术选型。只在确实需要最强推理能力时用 |
