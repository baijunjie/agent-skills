# 优化代码

- 范围只限本次会话改动的代码，不扩到无关部分；会话里没有改动时，以未提交的改动为准，也没有就问用户范围。
- 逐项检查三类问题：逻辑遗漏、冗余代码、可以优化的点（能复用现有实现、能删掉的分支与状态、明显的重复计算）。
- 逐条列出位置（`文件:行号`）与理由，只汇报，不直接修。
