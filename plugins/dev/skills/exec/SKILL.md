开发文档位置 / 补充说明：

请基于开发文档进行开发。开发前请根据开发文档中提及的内容，结合项目地图充分理解开发背景和上下文。

## 如何查看开发文档

- **总览文档**：每个开发任务目录下的 `README.md` 包含问题描述、解决方案概述、关键设计决策
- **里程碑文档**：按编号排序的文件，一份对应一个能独立测试、能独立合并的里程碑，开头点明目标与完成判据
- **依赖关系**：后续文档可能引用前面文档的内容，需要按顺序理解
- **只有 `README.md` 的目录**：说明这个主题只有一个里程碑，总览与里程碑内容都在这一份里，按它开发即可，不要因为「没有编号文档」而去拆分或补建文档

## 如何了解项目上下文

- **入口文档**：`@docs/README.md` 提供整体项目结构和模块索引
- **模块文档**：每个目录下的 `README.md` 说明该模块的功能和已实现内容
- **规范文档**：`@.claude/rules/` 目录下的开发规范和技术约束

## 开发任务完成标记

- **实时标记**：完成一个编号文档的开发后，立即重命名该文档，在文件名开头添加 `✅` 标记
- **禁止批量标记**：严禁等到所有任务完成后再统一添加标记
- **跳过已完成**：如果发现文件名包含 `✅` 标记，跳过该文档
- **单份文档不改名**：内容写在 `README.md` 里的主题，改名会破坏目录入口，改为在文档开头的目标 / 完成判据处标注 `✅ 已完成`
