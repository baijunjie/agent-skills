## 通用步骤

1. **写入 skill**：按下方当前宿主与作用域对应的安装节写入，已有的整份覆盖。
2. **对齐项目**：只在项目级安装时做。在装好的 `SKILL.md` 末尾加 `## 本项目` 一节，逐项写下表里
   写文案时必须知道、通用规范里没有的事实；查不到、用户也没交代的项不写，一项都没有就不加这一节。
   每条末尾记出处：查自项目的，写文件路径（文档再加章节标题原文）；用户交代的，写「用户交代」。

   | 项 | 记录什么 | 从哪来 |
   |---|---|---|
   | 语种 | 支持的语种清单 | 项目现状：资源文件里实际有的语种 |
   | 源语言 | 以哪种语言、哪一端为准同步 | 项目现状 |
   | 缺译回退 | 缺译时回退到哪种语言 | 项目现状：i18n 配置 |
   | 资源与命令 | 文案资源文件的位置，以及项目自带的排版、校验命令 | 项目现状 |
   | 术语表 | 易混概念各自的叫法、页面上必须写全称的对象 | 项目已有的术语表或文案，或用户交代 |
   | 豁免文件 | 不按界面语体改的文件（语音触发短语、法务、营销文案） | 项目现状 |
   | 规范文档 | 项目已有的文案规范文档路径 + 章节 | 项目现状 |
   | 风格选择 | 与模板默认不同的选择，逐项见下表；与默认相同的不写 | 项目已有文案的一贯写法，或用户交代 |

   风格选择的固定选项：

   | 选择 | 选项 |
   |---|---|
   | 各语言敬称档位 | 模板「各语言语体」表里的那一档（默认）；或项目另定的档位，如 de 用 Sie、es 用 usted |
   | zh-Hans / zh-Hant 括号 | 全角（默认）；或半角，整套半角 |
   | 日文 ASCII 词与假名、汉字之间 | 不加空格（默认）；或加半角空格 |
   | ko 请求句 | 해 주세요（默认）；或 -(으)십시오 |
   | zh-Hant 地区用语 | 台湾（默认）；或香港 |
   | es、it、pt-BR 引号 | “”（默认）；或项目另定的引号，如 « » |
   | Web 大小写 | 句首大写（默认）；或项目设计系统另行规定的写法 |

   项目文档里已写明的规则只指路，不复述。与通用规范冲突的项目约定写进这一节，不改通用正文。
3. **告知用户**：除各安装节列的外，说明重装时项目级的「本项目」一节会读出再填回（有出处的条目按现状重查），项目特有的文案约定请写进这一节。
