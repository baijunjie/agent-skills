默认只跑**受影响的测试**：本次新增或修改的测试文件，以及导入链（直接或间接）包含改动源文件的测试文件。框架自带按改动或依赖选测试的能力时优先用它，但确认它选出的范围覆盖这些。

改动波及全局（测试配置、全局 setup、共享辅助代码、依赖版本、构建配置、被大范围依赖的文件）、或依赖面查不清（动态导入、按字符串注册、反射、依赖注入，删除或改名了被引用的文件）时改跑**全量**，拿不准也跑全量。
